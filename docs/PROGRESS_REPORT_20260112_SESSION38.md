## 🔍 **技術的な発見**

### **問題1: チャンク分割による音声不良**

**原因**:
- 接続助詞（「ますが」等）で分割すると、次のチャンクが読点（、）から始まる
- OpenAI TTS-1-HDは読点から始まるテキストを正しく読めない

**具体例**:
```
チャンク3: "現在、月に10本の動画を外注していますが"
チャンク4: "、品質やコスト面での課題を抱えています。"
          ↑ 読点から始まる → TTSが正しく読めない
```

**解決策**:
- 句点（。）でのみ分割
- 自然な文の区切りを保つ

---

### **問題2: Oscillator音声の漏れ**

**原因**:
- MediaStreamDestinationをアクティブにするための20Hz Oscillator
- ミキサーGainNode経由でスピーカーにも接続されていた
- AI音声のGain増幅（4倍）により、Oscillatorも増幅されて聞こえた

**解決策**:
- Oscillatorを録画用Destinationのみに接続
- スピーカーには出力しない

---

### **問題3: Railway本番環境のキャッシュ問題**

**症状**:
- GitHubにプッシュしても古いコードが動く
- デバッグログが出力されない

**原因**:
- Railwayのビルドキャッシュ
- `logger.debug()` がINFOレベルでは表示されない

**解決策**:
- 空コミットで強制再デプロイ
