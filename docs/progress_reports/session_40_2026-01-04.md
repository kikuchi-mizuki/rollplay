#### 試行1: 音声トラックの有効化
**問題**: 録画データで音声が再生されない

**対応**:

**コミット**: `e30bcf2` - "fix: 録画データの音声トラックを確実に有効化して音声再生を修正"

#### 試行2: GainNodeを使った音声分岐
**問題**: AI音声が依然として録音されない
**原因**: AudioBufferSourceは使い捨てで、直接MediaStreamDestinationに接続すると新しい音声が再生されるたび接続が切れる
**対応**:
- GainNodeを導入して音声を分岐
- 接続順序: AudioBufferSource → GainNode → スピーカー & MediaStreamDestination

**コミット**: `a0167e3` - "fix: AI音声録音・ペルソナ一貫性・事業概要応答の3つの問題を修正"

#### 試行3: 直接接続方式（最終解決）
**問題**: GainNode経由でも録音されない（GainNodeも使い捨てで不安定）
**原因**: GainNodeを毎回新規作成していたため、接続が一時的
**対応**:
- GainNodeを削除し、AudioBufferSourceから直接両方に接続
- `source.connect(audioContext.destination)` - スピーカー
- `source.connect(audioDestinationRef.current)` - 録画用
- Web Audio APIの仕様上、1つのAudioNodeから複数出力先への接続は可能

**コミット**: `0b088a0` - "fix: AI音声録音の確実な実装と会話途中切れ問題の修正"

**最終的な実装**:
```typescript
// AudioBufferSourceを作成（毎回新規作成が必要）
const source = audioContext.createBufferSource();
source.buffer = audioBuffer;

// スピーカーに直接接続
source.connect(audioContext.destination);

// 録画用にMediaStreamDestinationにも直接接続
if (audioDestinationRef.current) {
  source.connect(audioDestinationRef.current);
}
```

## 🎯 技術的なポイント

### Web Audio API の正しい使い方
- **AudioBufferSource**: 使い捨て（一度`start()`したら再利用不可）
- **複数出力への接続**: 1つのAudioNodeから複数の出力先に接続可能
- **MediaStreamDestination**: Web Audio APIの音声をMediaStreamとしてキャプチャ
- **重要な発見**: 中間ノード（GainNode等）も使い捨てにすると不安定になる

### 最終的なアーキテクチャ
```
[AudioBufferSource] ──┬→ [AudioContext.destination] (スピーカー)
                       └→ [MediaStreamDestination] (録画)
```

### GPTパラメータのバランス
- `max_tokens`: 短すぎると途中で切れる、長すぎると冗長
- `temperature`: 高いほど自然だが、一貫性が低下
- 最終設定: `max_tokens=120`, `temperature=0.9`
