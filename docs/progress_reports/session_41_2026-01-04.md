### 1. ユーザー音声録音問題の解決（トラッククローン方式）

**問題**:
- 録画データにユーザー音声が入らない
- コンソールログで `readyState=ended` が表示される

**原因分析**:
- カメラのマイクトラックをVADレコーダーと録画で共有
- VADレコーダーが録音を開始すると、カメラストリームのトラックが停止
- 結果: 録画時にマイクトラックが `ended` 状態になる

**対応** (`57d00b2`):

#### トラッククローン実装（useRecording.ts）
```typescript
// カメラの音声トラック（VADレコーダーと競合しないようにクローン）
const cameraAudioTracks = cameraStream.getAudioTracks();
if (cameraAudioTracks.length > 0) {
  // トラックをクローンして追加（元のトラックはVADレコーダーで使用中）
  const clonedTracks = cameraAudioTracks.map(track => track.clone());
  audioTracks.push(...clonedTracks);
  console.log(`  カメラ音声: ${clonedTracks.length}トラッククローン追加`);
}

// AI音声トラック（再生終了の影響を受けないようにクローン）
const aiAudioTracks = aiStream.getAudioTracks();
if (aiAudioTracks.length > 0) {
  const clonedAiTracks = aiAudioTracks.map(track => {
    const cloned = track.clone();
    cloned.enabled = true;
    return cloned;
  });
  audioTracks.push(...clonedAiTracks);
  console.log(`  AI音声: ${clonedAiTracks.length}トラッククローン追加（有効化済み）`);
}
```

**結果**:
- ✅ ユーザー音声トラックが `readyState=live` になった
- ✅ VADレコーダーと録画で競合しなくなった

### 2. AI音声録音問題の根本解決（GainNodeミキサー常時接続方式）

**問題**:
- AI音声が録音されない
- コンソールログでは「🎙️ AI音声をMediaStreamDestinationに直接接続しました」と表示されるが、実際の録画ファイルには音声が含まれない

**原因分析**:
1. **MediaStreamDestinationの仕組み**:
   - MediaStreamDestinationは、接続されているノードから音声が流れている**瞬間だけ**データをストリームに送出
   - 音声が流れていない時は無音

2. **AudioBufferSourceの特性**:
   - 使い捨て（一度 `start()` したら再利用不可）
   - 毎回新規作成＆接続→再生終了時に自動切断

3. **MediaRecorderの動作**:
   - 録画開始時にトラックの"スナップショット"を取得
   - その時点でMediaStreamDestinationに音声が流れていない
   - 後から音声が流れても、既にキャプチャ対象外

**試行錯誤の履歴**:

#### 試行1: 直接接続方式（セッション40で実装）
```typescript
source.connect(audioContext.destination);        // スピーカー
source.connect(audioDestinationRef.current);     // MediaStreamDestination
```
**結果**: ❌ 失敗（録画開始時に音声が流れていないため）

#### 試行2: トラッククローン（本セッション前半）
```typescript
const clonedAiTracks = aiAudioTracks.map(track => track.clone());
audioTracks.push(...clonedAiTracks);
```
**結果**: ❌ 失敗（トラック自体は `live` だが、データが流れていない）

#### 試行3: GainNodeミキサー常時接続方式（最終解決）

**対応** (`994c613`):

**アーキテクチャ変更**:
```
[初期化時（録画開始前）]
GainNode(常時接続) ──┬→ MediaStreamDestination → MediaRecorder
                      └→ AudioContext.destination(スピーカー)

[AI音声再生時]
AudioBufferSource → GainNode(既に接続済み) → 自動的に録画＆スピーカーへ
```

**実装内容**:

##### 1. GainNode追加（RoleplayApp.tsx）
```typescript
const aiMixerGainNodeRef = useRef<GainNode | null>(null); // AI音声ミキサー用GainNode（常時接続）
```

##### 2. 初期化時にGainNodeを常時接続（initializeAudio）
```typescript
// MediaStreamDestinationを作成
const destination = audioContext.createMediaStreamDestination();
audioDestinationRef.current = destination;

// AI音声ミキサー用のGainNodeを作成（常時接続）
const mixerGain = audioContext.createGain();
mixerGain.gain.value = 1.0;
mixerGain.connect(destination); // MediaStreamDestinationに常時接続
mixerGain.connect(audioContext.destination); // スピーカーにも常時接続
aiMixerGainNodeRef.current = mixerGain;

console.log('✅ AI音声出力ストリーム作成完了（GainNodeミキサー方式）');

// ダミーの無音バッファを再生してMediaStreamDestinationをアクティブ化
const buffer = audioContext.createBuffer(1, 1, 22050);
const source = audioContext.createBufferSource();
source.buffer = buffer;
source.connect(mixerGain); // ミキサー経由で接続
source.start(0);
```

##### 3. AI音声再生時にGainNodeに接続（playAudioWithWebAudio）
```typescript
// AudioBufferSourceを作成
const source = audioContext.createBufferSource();
source.buffer = audioBuffer;

// AI音声ミキサーGainNodeに接続（常時接続されているので、ここに流すだけで録音される）
if (aiMixerGainNodeRef.current) {
  source.connect(aiMixerGainNodeRef.current);
  console.log('🎙️ AI音声をミキサーGainNodeに接続しました（録音対応）');
} else {
  // フォールバック：ミキサーがない場合は直接スピーカーに接続
  source.connect(audioContext.destination);
  console.warn('⚠️ ミキサーGainNodeが未初期化、直接スピーカーに接続');
}
```

**結果**:
- ✅ GainNodeが常時MediaStreamDestinationに接続
- ✅ AI音声が再生されるたびに自動的にMediaStreamDestinationに流れる
- ✅ MediaRecorderが確実にキャプチャできる

## 🎯 技術的なポイント

### MediaStreamTrack.clone() の重要性
- **問題**: 1つのトラックを複数の用途で共有すると、一方が停止すると他方も影響を受ける
- **解決**: `track.clone()` で独立したトラックを作成
- **用途**:
  - カメラ音声: VADレコーダーと録画で別々のトラック
  - AI音声: 元のトラックと録画用で別々のトラック

### GainNodeの常時接続パターン
- **従来の問題**: AudioBufferSourceを直接MediaStreamDestinationに接続すると、再生終了時に切断される
- **解決**: GainNodeを仲介して常時接続を維持
- **メリット**:
  - AudioBufferSourceは使い捨てでも問題なし
  - GainNodeは常時接続されているため、音声が流れるたびに自動的に録音される
  - 音量調整も可能（gain.value）

### Web Audio APIの接続ルール
1. **AudioNode間の接続は永続的**: `connect()` で接続したら、明示的に `disconnect()` するまで維持
2. **AudioBufferSourceは例外**: 一度 `start()` したら、再生終了時に自動的に全ての接続が切断される
3. **GainNodeは永続的**: 一度接続したら、明示的に切断するまで維持される

### 最終的なアーキテクチャ
```
[ユーザー音声]
カメラマイク → clone() → 録画用トラック → MediaRecorder

[AI音声]
AudioBufferSource → GainNode(常時接続) ─┬→ MediaStreamDestination → MediaRecorder
                                        └→ AudioContext.destination(スピーカー)
```
