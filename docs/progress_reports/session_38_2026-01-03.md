### 4. ✅ AI音声も録音に含めるように対応

- **コミット**: 200dac6
- **問題**: AIの音声が録音されていない
- **原因**: Web Audio APIの出力が録音に含まれていない
- **実装内容**:
  1. **AudioContextからMediaStreamDestinationを作成**
     ```typescript
     const destination = audioContext.createMediaStreamDestination();
     audioDestinationRef.current = destination;
     setAiAudioStream(destination.stream);
     ```
  2. **AI音声再生時にdestinationにも接続**
     ```typescript
     source.connect(audioContext.destination); // スピーカーに出力
     if (audioDestinationRef.current) {
       source.connect(audioDestinationRef.current); // 録画用
     }
     ```
  3. **RecordingStreamsインターフェースを拡張**
     - `aiAudioStream?: MediaStream | null` を追加
  4. **Canvas合成時にAI音声トラックも追加**
     - カメラのみモード: カメラ音声 + AI音声
     - 画面共有+カメラ: 画面共有音声 + カメラ音声 + AI音声

**成果**: ✅ ユーザーの声とAIの応答の両方が録音される

### 5. ✅ アプリ起動時にWeb Audio APIを初期化

- **コミット**: ac31024
- **問題**: AIの音声が録音されない（前のタスクの修正後も）
- **原因**: 録画開始時にWeb Audio APIが未初期化（初期化は最初のAI音声再生時）
- **修正内容**:
  - アプリ起動時にinitializeAudio()を呼び出すuseEffectを追加
  ```typescript
  useEffect(() => {
    const init = async () => {
      if (!audioInitialized) {
        console.log('🎵 アプリ起動時にWeb Audio APIを初期化します（録画用）');
        await initializeAudio();
      }
    };
    init();
  }, []);
  ```

**成果**: ✅ 録画開始前にaiAudioStreamが確実に作成される
