## ⚠️ 重要な学び

### 1. Railwayのビルドキャッシュ問題

**問題**: Railwayが古いビルドキャッシュを保持し、最新のコードが反映されない

**原因**:
- Railwayがビルド時に古いdistフォルダをキャッシュから復元
- `npm run build`が実行されても、古いファイルが残る

**解決**:
- distフォルダを一時的にGitにコミット（緊急対応）
- 空のコミットで再デプロイをトリガー

**教訓**:
- デプロイ環境のキャッシュ動作を理解する
- 本番環境での確認が重要
- ブラウザキャッシュとサーバーキャッシュの両方を考慮する

### 2. ブラウザキャッシュの影響

**問題**: Railwayが最新ビルドを配信しても、ブラウザが古いキャッシュを使用

**原因**:
- ブラウザがJSファイルをキャッシュ
- ファイル名が同じだとキャッシュが更新されない

**解決**:
- ハードリロード（Cmd+Shift+R）
- シークレットモード/プライベートモードで確認
- Chrome DevToolsで「Disable cache」を有効化

**教訓**:
- ファイル名にハッシュを含める（Viteは自動的に行う）
- ユーザーにキャッシュクリアの方法を案内する

### 3. UX改善の重要性

**問題**: ユーザーが間違ったGoogleアカウントでログインした場合、変更が困難

**解決**: アカウント登録画面に「変更」ボタンを追加

**教訓**:
- ユーザーのミスを想定した設計
- 簡単に訂正できる仕組みが重要
- 小さな改善がUXを大きく向上させる
