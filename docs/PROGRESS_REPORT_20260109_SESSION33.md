### 3. AI英語発話問題を修正

#### **問題1: システムプロンプトに日本語指示がない**:
- AIが時々英語で話し始める
- システムプロンプトに「日本語で回答」という明示的な指示がなかった

**解決策**:
**app.py (line 656-662)**:
```python
## 🌐 言語設定

**必ず日本語で回答してください。**
- すべての発言は日本語で行う
- 英語や他の言語を使用しない
- 日本のビジネス慣習に従った自然な日本語で話す
- **ビジネス用語（CVR、SNS、ROI等）はそのまま使用して良い**が、文章全体は日本語で構成する
```

#### **問題2: TTS音声に英語が混ざる** (コミット: e479e8c):
- AIのテキストは日本語（「現在、広告のCVRが低く、SNS動画制作を検討しています」）
- しかしOpenAI TTSが英語略語（CVR、SNS）を英語として認識し、英語発音していた

**解決策**:

**テキスト正規化関数を追加** (blueprints/media.py:81-126):
```python
def normalize_text_for_japanese_tts(text):
    """
    日本語TTS用にテキストを正規化
    英語略語をカタカナ読みに変換して、TTSが英語発音するのを防ぐ
    """
    replacements = {
        'CVR': 'シーブイアール',
        'SNS': 'エスエヌエス',
        'ROI': 'アールオーアイ',
        'KPI': 'ケーピーアイ',
        # ... 全25種類のビジネス用語
    }
    # 単語境界で置換
    for eng, jpn in replacements.items():
        text = re.sub(r'\b' + eng + r'\b', jpn, text)
    return text
```

**TTS生成時に正規化を適用**:
- media.py: text_to_speech()エンドポイント
- conversations.py: chat_stream()内のTTS生成

**対応したビジネス用語（25種類）**:
CVR, SNS, CPA, ROI, KPI, CEO, CTO, SEO, UI, UX, API, DX, IT, PR, BtoB, BtoC, AI, ML, SaaS, PaaS, IaaS, LP, CRM, EC

**効果**:
- **変更前**: 「...コンバージョンレート...**ソーシャルネットワーク**...」← 英語発音
- **変更後**: 「...シーブイアール...エスエヌエス...」← 日本語カタカナ発音 ✅

### 4. 録画ボタンで自動的に画面共有を開始（後に削除）

#### **試行 - ワンクリック録画** (コミット: 6531787):

**実装内容**:
```typescript
const startVideoRecording = useCallback(async () => {
  // 画面共有が未起動の場合は自動的に開始
  if (!isScreenSharing) {
    await startScreenShare();
    await new Promise(resolve => setTimeout(resolve, 500));
  }
  // 録画開始
  startVideoRecordingInternal();
}, [isScreenSharing, startScreenShare]);
```

**問題点**:
- ユーザーの意図: 「録画を押したら画面全体が録画される」
- しかし、実際には「録画を押すと画面共有ダイアログが表示される」
- ユーザーの期待と動作が不一致

#### **修正 - 元の動作に戻す** (コミット: ca4ac25):

**理由**:
- ブラウザのセキュリティ制約上、JavaScriptだけでは画面共有なしで画面全体を録画することは**技術的に不可能**
- `getDisplayMedia()` API（画面共有）を使う必要がある
- すべてのブラウザで共通の制約

**最終的な動作**:
- **方法1: 画面全体を録画（推奨）**
  1. 画面共有ボタンをクリック → 「このタブ」を選択
  2. 録画ボタンをクリック
  3. 画面全体（UI、アバター、字幕すべて）が録画される

- **方法2: カメラのみ録画**
  1. 録画ボタンをクリック（画面共有なし）
  2. カメラ映像とアバターが合成されて録画される

**解決**:

- 単語境界を考慮した置換（誤変換防止）
