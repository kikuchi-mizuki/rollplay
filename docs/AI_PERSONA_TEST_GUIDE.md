## 💬 使い方

### 基本的な会話

営業役として質問を入力すると、AIが顧客役として応答します。

```
営業👨‍💼: こんにちは、本日はお時間いただきありがとうございます

顧客🧑‍💼: はい、よろしくお願いします
```

### 特殊コマンド

| コマンド | 機能 |
|---------|------|
| `exit` | 終了 |
| `reset` | 会話をリセット |
| `show` | システムプロンプトを表示 |
| `persona` | ペルソナ情報を表示 |
| `Ctrl+C` | 終了 |

## 🎯 確認すべきポイント

### 1️⃣ **応答の長さ**

**最初の1-2往復**（超簡潔）:
```
営業👨‍💼: 本日はお時間いただきありがとうございます

顧客🧑‍💼: はい
```
→ ✅ 10-20文字程度で簡潔

**営業がオープンクエスチョンをしたら**（少し詳しく）:
```
営業👨‍💼: 現在、どんな課題がありますか？

顧客🧑‍💼: そうですね...自社で動画作ってるんですけど、なかなか本数がスケールしなくて
```
→ ✅ 20-40文字程度

**営業が具体的に掘り下げたら**（詳細）:
```
営業👨‍💼: 月に何本くらい作られてますか？

顧客🧑‍💼: うーん、繁忙期だと15本とか20本は社内で作ってて...
        でも閑散期は5本くらいで。正直、安定しないんですよね
```
→ ✅ 40-80文字程度

### 2️⃣ **ペルソナ設定の反映**

**事業内容を聞かれた時**:
```
営業👨‍💼: どんな事業をされてるんですか？

顧客🧑‍💼: あー、[シナリオ設定の事業詳細が反映される]
```

**確認方法**:
```
# ペルソナ情報を表示
persona
```

### 3️⃣ **自然な話し方**

**良い例**（フィラー・間を使う）:
```
顧客🧑‍💼: えーと、繁忙期だと15本とか20本は作ってて...
        でも、閑散期は5本くらいで。
        うーん、正直安定しないんですよね
```

**悪い例**（機械的）:
```
顧客🧑‍💼: 繁忙期は15-20本、閑散期は5-10本制作しています。
```

### 4️⃣ **段階的な情報開示**

**営業が聞かない限り、詳細を話さない**:
```
営業👨‍💼: 動画制作されてますか？
顧客🧑‍💼: そうですね、自社で作ってて...

営業👨‍💼: 月に何本くらいですか？
顧客🧑‍💼: 繁忙期だと15本とか...

営業👨‍💼: 課題はありますか？
顧客🧑‍💼: うーん、本数がスケールしないのと...
```

→ ✅ 営業の質問に応じて段階的に開示

### 5️⃣ **役割の一貫性**

**NG例**（営業のように質問してしまう）:
```
顧客🧑‍💼: そうですね、動画作ってて...
        ところで、御社のサービスはどんな内容ですか？
```
→ ❌ 顧客が営業に質問するのはNG

**OK例**（顧客として応答）:
```
顧客🧑‍💼: そうですね、動画作ってて...
        でも、なかなか本数がスケールしなくて困ってます
```
→ ✅ 顧客として悩みを話す

## 📋 チェックリスト

### 応答の品質

- [ ] 最初は簡潔（10-20文字）
- [ ] 営業の質問に応じて徐々に詳しく
- [ ] フィラー（「えーと」「そうですね...」）を使用
- [ ] 間（「...」）を適度に使用
- [ ] 具体的な数字や固有名詞を含む
- [ ] 自然な話し言葉（「〜なんですよ」「〜って感じで」）

### ペルソナ設定

- [ ] シナリオ設定の「事業詳細」が反映されている
- [ ] 「SNS運用状況」が反映されている
- [ ] 「具体的な課題」が反映されている
- [ ] 「予算感」が反映されている
- [ ] 「トーン・態度」が反映されている

### 役割の一貫性

- [ ] 顧客として応答している（営業のように質問しない）
- [ ] 営業のサービス説明をしない
- [ ] 自分の悩みや課題を話す
- [ ] 段階的に情報を開示する

## 🎯 よくある問題と解決法

### Q1: AIが営業のように質問してくる

**確認**:
```
show
```

「絶対に禁止: 営業のように質問すること」が含まれているか確認。

**解決**:
- システムプロンプトを再確認
- `reset`で会話をリセット

### Q2: 応答が機械的（フィラーがない）

**確認**:
```
show
```

「フィラーや間を積極的に使う」セクションを確認。

**解決**:
- Temperature設定を確認（0.7が推奨）
- RAG強化が有効になっているか確認

### Q3: ペルソナ設定が反映されない

**確認**:
```
persona
```

期待する情報が含まれているか確認。

**解決**:
- シナリオファイルを確認
- app.pyでペルソナ情報が正しく読み込まれているか確認
