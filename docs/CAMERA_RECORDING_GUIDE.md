## 🚀 使用方法

### 1. カメラを開始

**画面右上のテストボタンエリア**

1. **📷 Camera ON** ボタンをクリック
2. ブラウザの権限ダイアログで「許可」をクリック
3. カメラ映像が右下に表示される（PinP形式）

**エラーが出る場合**:
- カメラが接続されているか確認
- 他のアプリ（Zoom、Teams等）でカメラを使用していないか確認
- ブラウザの設定でカメラアクセスが許可されているか確認

---

### 2. 画面共有を開始

**画面右上のテストボタンエリア**

1. **🖥️ Screen Share** ボタンをクリック
2. 共有対象を選択:
   - **デスクトップ全体**
   - **特定ウィンドウ**（PowerPoint、PDF等）
   - **ブラウザタブ**
3. 「共有」をクリック
4. 画面共有映像がメインエリアに全画面表示される
5. カメラPinPは右下に継続表示

**停止方法**:
- **⏹️ Stop Share** ボタンをクリック
- またはブラウザの「共有を停止」ボタンをクリック

---

### 3. 録画を開始

**前提条件**: カメラがONになっている必要があります

**画面右上のテストボタンエリア**

1. カメラをONにする（📷 Camera ON）
2. **🎬 Start Recording** ボタンをクリック
3. 録画中は以下が表示される:
   - ボタンが「⏺️ Recording 00:00」に変化（点滅）
   - カメラPinPに「REC 00:00」インジケーター
   - 録画時間がリアルタイム更新（MM:SS形式）
4. 録画を停止するには「⏺️ Recording 00:00」ボタンをクリック
5. 録画完了後、Toast通知に録画情報が表示される:
   ```
   録画完了！ (2.45 MB, 15秒)
   ```

**注意事項**:
- カメラがOFFの場合、録画ボタンは無効化されます
- 現在はカメラのみ録画（Day 6で画面共有+カメラの合成録画を実装予定）
- 録画データはメモリ上に保持（Day 7でダウンロード機能を実装予定）

### Day 5テスト項目チェックリスト

#### 1. カメラアクセステスト

- [ ] **正常系**: カメラONボタンをクリック → カメラ映像が右下に表示される
- [ ] **エラー系（拒否）**: 権限ダイアログで「ブロック」→ エラーメッセージ表示
- [ ] **エラー系（カメラなし）**: カメラ未接続環境 → エラーメッセージ表示

**期待動作**:

- PinPサイズ: 320×240px
- 配置: 右下（bottom-4 right-4）
- エラーメッセージ: Toast通知で表示

#### 2. 画面共有テスト

#### 3. 録画機能テスト

- [ ] **前提条件**: カメラOFF状態 → 録画ボタンが無効化されている
- [ ] **正常系**: カメラON → 録画開始 → 録画中インジケーター表示

- [ ] **録画停止**: 録画停止 → Toast通知に録画情報表示（サイズ、時間）

## 🛠️ トラブルシューティング

### カメラが映らない

**原因1**: カメラへのアクセスが拒否されている
- **対処**: ブラウザの設定 → サイトの設定 → カメラ → 許可

**原因2**: カメラが他のアプリで使用中
- **対処**: Zoom、Teams、Skype等を終了

**原因3**: カメラが接続されていない
- **対処**: 外付けカメラの接続を確認

---

### 画面共有が開始できない

**原因1**: 画面収録の権限がない（macOS）
- **対処**: システム環境設定 → セキュリティとプライバシー → 画面収録 → ブラウザにチェック

**原因2**: ブラウザが画面共有に未対応
- **対処**: Chrome、Firefox、Safari、Edgeを使用

---

### 録画ボタンが押せない

**原因**: カメラがONになっていない
- **対処**: 先に「📷 Camera ON」ボタンをクリック

---

### 録画が途中で止まる

**原因1**: カメラストリームが切断された
- **対処**: カメラ接続を確認

**原因2**: メモリ不足
- **対処**: 他のタブやアプリを閉じる、録画時間を短くする
