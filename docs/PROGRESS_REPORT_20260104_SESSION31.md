## 🔧 技術的ハイライト

### 1. レスポンス速度と自然さのトレードオフ

**課題**:
- 速度重視 → 応答が短すぎる、細切れで不自然
- 自然さ重視 → 最初のチャンクまで時間がかかる

**解決策**:
- 接続助詞での分割を導入
- 適切な接続助詞のみを厳選
- バッファサイズと最低文字数を調整

### 2. 日本語の文法理解

**発見した問題**:
- 「て」「し」は接続助詞ではなく、動詞の活用形
- これらで分割すると文の途中で切れて不自然

**対策**:
- 接続助詞リストから「て」「し」を削除
- 本物の接続助詞のみに限定
