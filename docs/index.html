システム概要

このシステムは、ショート動画制作営業のロープレ（ロールプレイング）練習を、AIを使って一人で行えるシステムです。

主な機能

  • 音声会話：マイクで話しかけると、AIお客様が音声で返答します
  • リアルなペルソナ：美容サロン、飲食店、不動産など、様々な業種のお客様と会話できます
  • 段階別シナリオ：初回面談からクロージングまで、4段階のシナリオを用意
  • 詳細な講評：会話終了後、GPT-4があなたの営業スキルを4項目で評価します
【こんな方におすすめ】
  • 新人営業で、実践練習の場が欲しい
  • 営業トークのパターンを増やしたい
  • クロージングまでの流れを体得したい
  • 客観的な評価が欲しい

ログイン・登録

システムを利用するには、まずアカウントの登録とログインが必要です。

初めての方：アカウント登録

ステップ1：登録ページにアクセス

システムのURLにアクセスすると、ログイン画面が表示されます。

画面下部の「アカウントをお持ちでない方はこちら」または「新規登録」ボタンをクリックします。

ステップ2：必要情報を入力

以下の情報を入力します：

  • メールアドレス：ログイン時に使用します
  • パスワード：8文字以上を推奨
  • 名前：システム内で表示される名前
  • 店舗コード（組織での利用の場合）：管理者から提供されたコード

ステップ3：登録完了

「登録」ボタンをクリックすると、アカウントが作成されます。

登録が完了すると、自動的にログインされ、ロープレシステムのトップページに移動します。

既にアカウントをお持ちの方：ログイン

ログイン手順

  1. システムのURLにアクセス
  2. メールアドレスとパスワードを入力
  3. 「ログイン」ボタンをクリック

ログインに成功すると、ロープレシステムのトップページに移動します。

【パスワードを忘れた場合】

ログイン画面の「パスワードをお忘れですか？」リンクから、パスワードリセットの手続きができます。登録したメールアドレスにリセット用のリンクが送信されます。

【組織での利用について】

企業や店舗で複数人で利用する場合、管理者から「店舗コード」が提供されます。登録時にこのコードを入力することで、組織内での練習履歴や統計を共有できます。

事前準備

必要なもの

  1. パソコンまたはスマートフォン
    • Chrome、Safari、Edgeなどのモダンブラウザ
    • マイク機能が使えるデバイス
  2. 静かな環境
    • 音声認識の精度を上げるため、できるだけ静かな場所で利用してください
  3. イヤホン・ヘッドセット（推奨）
    • スピーカーからの音声をマイクが拾ってしまうのを防ぎます
【初回アクセス時の注意】

初めてアクセスすると、ブラウザから「マイクの使用を許可しますか？」と聞かれます。必ず「許可」を選択してください。許可しないと音声入力ができません。

基本的な使い方

以下の手順で、ロープレを始めることができます。

ステップ1：システムにアクセス

ブラウザでシステムのURLを開き、ログインします。

ログイン後、ロープレシステムのトップページが表示されます。

ステップ2：シナリオを選択

画面上部の「シナリオ選択」から、練習したいシナリオを選びます。

  • 1次面談：初回接触、関係構築（初心者向け）
  • 1.5次面談：2回目、課題ヒアリング（初心者～中級者向け）
  • 2次面談：3回目、提案・見積提示（中級者向け）
  • 3次面談：4回目、クロージング（中級者～上級者向け）
シナリオ選択画面のスクリーンショット（今後追加予定）

ステップ3：ペルソナを選択

「ペルソナ選択」ボタンをクリックして、お客様の業種を選びます。

  • おまかせ：ランダムに選択（推奨）
  • 個別選択：美容サロン、飲食店、不動産など、特定の業種を選択
【初めての方へ】

最初は「おまかせ」でランダム選択がおすすめです。様々な業種のお客様と話すことで、対応力が身につきます。

ペルソナ選択画面のスクリーンショット（今後追加予定）

ステップ4：難易度を選択

お客様の態度や質問の難易度を3段階から選べます。

  • 初級：お客様が協力的で、質問に丁寧に答えてくれます
  • 中級：適度に警戒心があり、営業のスキルに応じて態度が変わります
  • 上級：警戒心が強く、簡単には心を開きません

ステップ5：ロープレ開始

「ロープレ開始」ボタンをクリックすると、AIお客様との会話が始まります。

  1. 画面中央のマイクボタンを長押ししながら話します
  2. 話し終わったら、マイクボタンから指を離します
  3. AIお客様が音声で返答します
  4. このやり取りを繰り返します
【上手に話すコツ】
  • マイクボタンを押してから、0.5秒待ってから話し始める
  • ゆっくり、はっきりと話す
  • 一文ごとに区切って話す（長すぎる文は避ける）
ロープレ画面のスクリーンショット（今後追加予定）

ステップ6：ロープレ終了

会話が一段落したら、「講評をもらう」ボタンをクリックします。

GPT-4があなたの営業スキルを分析し、詳細な講評を表示します。

シナリオの説明

シナリオは、営業の商談フェーズに応じて4種類用意されています。

1次面談（初回接触・関係構築）

初心者向け 初回接触

目標：お客様の警戒心を解き、信頼関係を構築する

お客様の態度：慎重で、あまり多くを話してくれない

重点スキル：

  • ヒアリング力（30%）：現状を自然に聞き出す
  • 共感力（30%）：不安を受け止める
  • 提案力（20%）：押し売りせず、軽い提案をする
  • 信頼構築（20%）：次回面談につなげる

会話の流れ：挨拶 → ニーズ分析 → 軽い提案 → 次回アポイント

1.5次面談（課題ヒアリング）

初心者～中級者向け 2回目の接触

目標：お客様の課題を深く理解し、具体的なニーズを引き出す

お客様の態度：少し心を開いており、質問に答えてくれる

重点スキル：

  • 質問力（35%）：深掘りする質問ができるか
  • 傾聴力（30%）：話をしっかり聞けるか
  • 提案力（20%）：方向性を示せるか
  • 信頼構築（15%）：さらに関係を深める

会話の流れ：前回の振り返り → 課題の深掘り → 方向性の提示 → 次回提案の予告

2次面談（提案・見積提示）

中級者向け 3回目の接触

目標：具体的な提案と見積を提示し、お客様の理解を得る

お客様の態度：前向きだが、費用対効果を気にしている

重点スキル：

  • 提案力（40%）：具体的で魅力的な提案ができるか
  • 質問力（25%）：懸念点を引き出せるか
  • 傾聴力（20%）：フィードバックを受け止められるか
  • クロージング（15%）：次のステップを提示できるか

会話の流れ：挨拶 → 提案説明 → 質疑応答 → 懸念解消 → 次回クロージングの予告

3次面談（クロージング・契約）

中級者～上級者向け 4回目の接触

目標：最終確認を行い、契約につなげる

お客様の態度：ほぼ決定に向かっているが、最終確認が必要

重点スキル：

  • クロージング力（50%）：自然に契約につなげられるか
  • 提案力（20%）：最終条件を整理できるか
  • 質問力（20%）：最終確認事項を漏れなく把握できるか
  • 共感力（10%）：残る懸念に寄り添えるか

会話の流れ：挨拶 → 最終確認 → 懸念解消 → 契約条件の確認 → クロージング

【シナリオの選び方】
  • 初めての方：まずは「1次面談」から始めましょう
  • 慣れてきたら：1次→1.5次→2次→3次と順番に練習すると、商談の流れが体得できます
  • 特定スキルを鍛えたい：苦手なフェーズを重点的に練習しましょう

ペルソナの選び方

ペルソナとは、AIお客様の「設定」のことです。業種、現状、課題、予算感などが設定されています。

ペルソナの種類

業種 特徴 難易度
美容サロン Instagram重視、ビジュアル重視 中
飲食店 予算に敏感、効果を重視 中
不動産 堅実、データ重視 高
フィットネス SNS活用に前向き 中
小売店 コスト重視、効果測定に敏感 高

選び方のポイント

【おまかせ（ランダム選択）がおすすめな理由】
  • 様々な業種のお客様と話すことで、対応力が身につく
  • 予想外の質問や展開に対応する練習になる
  • 実際の営業では、様々な業種のお客様と話す機会があるため、実践的
【特定の業種を選ぶ場合】
  • 担当エリアに多い業種を重点的に練習したい
  • 苦手な業種を克服したい
  • 特定の業種の知識を深めたい

講評の見方

ロープレ終了後、GPT-4があなたの会話を分析し、以下の4項目で評価します。

評価項目（営業向け）

1. 質問力（Questioning Skill）

顧客のニーズや課題を適切に引き出す質問ができているか

良い例：

  • 「現在、動画制作で困っていることはありますか？」
  • 「月に何本くらいの投稿を目標にされていますか？」

改善点の例：

  • 抽象的すぎる質問（「何かお困りですか？」）
  • クローズドクエスチョンばかり（「動画は作っていますか？」→「はい/いいえ」で終わる）

2. 傾聴力（Listening Skill）

相手の発言を理解し、適切に受容・共感できているか

良い例：

  • 「なるほど、外注コストが課題なんですね」
  • 「確かに、毎月の制作は大変ですよね」

改善点の例：

  • お客様の話を遮る
  • 共感せずに次の質問に移る

3. 提案力（Proposal Skill）

顧客の課題に対する具体的な解決策を提示できているか

良い例：

  • 「月10本のショート動画を定額で制作できます」
  • 「Instagram用に縦型動画を作成し、リール投稿をサポートします」

改善点の例：

  • 抽象的な提案（「動画制作をお手伝いします」）
  • お客様のニーズと合っていない提案

4. クロージング力（Closing Skill）

次のアクションや決定を促す適切なクロージングができているか

良い例：

  • 「次回、具体的なプランをご提案させていただけますか？」
  • 「来週、サンプル動画をお持ちしますね」

改善点の例：

  • 次のステップを提示せずに終わる
  • 強引すぎるクロージング（「今日決めてください」）

スコアの見方

スコア 評価 説明
5点 非常に優れている プロレベル、模範的なトーク
4点 優れている 実践的なスキルが十分にある
3点 平均的 基本スキルはあるが、改善点が複数ある
2点 要改善 基本スキルが不足している
1点 大幅な改善が必要 スキルがほとんど発揮されていない
【講評の活用方法】
  • 良かった点：次回も継続して実践しましょう
  • 改善点：具体的な改善方法が書かれているので、次回のロープレで意識しましょう
  • 具体例：自分の実際の発言が引用されているので、振り返りに活用しましょう
  • 次回のアクションプラン：次のロープレで実践すべきことが3つ提示されます

使いこなすコツ

1. 会話を長く続けるコツ

  • 挨拶だけで終わらず、必ずヒアリング → 提案 → クロージングまで進める
  • お客様の回答に対して、さらに深掘りする質問をする
  • 会話の途中で「講評をもらう」を押さず、自然な終わり方を目指す

2. スコアを上げるコツ

  • 質問力：オープンクエスチョンを使う（「どのような～」「何が～」）
  • 傾聴力：お客様の発言を要約して確認する（「つまり～ということですね」）
  • 提案力：具体的な数字を使う（「月10本」「月額5万円」など）
  • クロージング力：必ず次のアクションを提示する

3. 音声認識の精度を上げるコツ

  • マイクボタンを押してから、0.5秒待ってから話し始める
  • ゆっくり、はっきりと話す（早口にならない）
  • 一文ごとに区切る（長い文は避ける）
  • イヤホン・ヘッドセットを使う
  • 静かな環境で練習する

4. 効果的な練習方法

  • 毎日少しずつ：1日1回、10分だけでも続ける
  • シナリオを順番に：1次→1.5次→2次→3次と順番に練習
  • 同じシナリオを繰り返す：1つのシナリオを3回以上練習すると、パターンが身につく
  • 講評を読み返す：次のロープレ前に、前回の講評を見直す

よくある質問

Q1. AIお客様が「すみません、もう一度お願いできますか？」と頻繁に言います

A. 以下を確認してください：

  • 静かな環境で話していますか？
  • マイクボタンを押してから、0.5秒待ってから話していますか？
  • 一文が長すぎませんか？（一文は20文字程度が理想）
  • イヤホン・ヘッドセットを使っていますか？

Q2. 講評のスコアが低いです

A. スコアが低い場合、以下の可能性があります：

  • 挨拶だけで終わっている → ヒアリング、提案、クロージングまで進めましょう
  • 基本的な質問しかしていない → 深掘りする質問を意識しましょう
  • 会話が短すぎる → 最低でも5往復以上は会話しましょう

講評の「改善点」をよく読んで、次回のロープレで実践してみてください。

Q3. AIお客様の声が聞こえません

A. 以下を確認してください：

  • デバイスの音量がミュートになっていませんか？
  • ブラウザの音声再生が許可されていますか？
  • イヤホンやスピーカーが正しく接続されていますか？

Q4. 会話の途中でやり直したいです

A. 画面右上の「リセット」ボタンをクリックすると、会話をやり直せます。

Q5. 講評はどこに保存されますか？

A. 講評は自動的にデータベースに保存されます。過去の講評は「履歴」から確認できます。

Q6. スマホでも使えますか？

A. はい、スマートフォンのブラウザでも利用できます。Chrome、Safariなどのモダンブラウザを使用してください。
