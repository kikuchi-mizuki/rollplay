システム概要

このシステムは、ショート動画制作の営業・ディレクター業務のロープレ（ロールプレイング）練習を、AIを使って一人で行えるシステムです。

2つのロール

営業ロール

ショート動画制作サービスの営業として、クライアントへの提案営業を練習します。初回面談からクロージングまでの商談プロセスを体験できます。

ディレクターロール

ショート動画制作のディレクターとして、クライアントからの制作要件のヒアリング・提案を練習します。目的の引き出しから具体的な制作プランの立案までを体験できます。

主な機能

  • 音声会話：マイクで話しかけると、AIクライアント（お客様）が音声で返答します
  • リアルなペルソナ：美容サロン、飲食店、不動産など、様々な業種のクライアントと会話できます
  • 段階別シナリオ：営業は初回面談からクロージングまで6段階、ディレクターは初回ヒアリングシナリオを用意
  • 詳細な講評：会話終了後、GPT-4があなたのスキルを4項目で評価します
【こんな方におすすめ】
  • 新人営業・新人ディレクターで、実践練習の場が欲しい
  • 営業トークやヒアリングのパターンを増やしたい
  • クライアントとのコミュニケーションスキルを向上させたい
  • 客観的な評価とフィードバックが欲しい

ログイン・登録

システムを利用するには、まずアカウントの登録とログインが必要です。

初めての方：アカウント登録

ステップ1：登録ページにアクセス

システムのURLにアクセスすると、ログイン画面が表示されます。

画面下部の「アカウントをお持ちでない方はこちら」または「新規登録」ボタンをクリックします。

ステップ2：必要情報を入力

以下の情報を入力します：

  • メールアドレス：ログイン時に使用します
  • パスワード：8文字以上を推奨
  • 名前：システム内で表示される名前
  • 店舗コード（組織での利用の場合）：管理者から提供されたコード

ステップ3：登録完了

「登録」ボタンをクリックすると、アカウントが作成されます。

登録が完了すると、自動的にログインされ、ロープレシステムのトップページに移動します。

既にアカウントをお持ちの方：ログイン

ログイン方法1：メールアドレスとパスワードでログイン

  1. システムのURLにアクセス
  2. メールアドレスとパスワードを入力
  3. 「ログイン」ボタンをクリック

ログインに成功すると、ロープレシステムのトップページに移動します。

ログイン方法2：Googleアカウントでログイン

Googleアカウントを使って、簡単にログインできます。

  1. システムのURLにアクセス
  2. 「Googleでログイン」ボタンをクリック
  3. Googleのログイン画面が表示されるので、使用するGoogleアカウントを選択
  4. 必要に応じてパスワードを入力
  5. ログインを許可する

初回のGoogleログイン時は、自動的にアカウントが作成されます。2回目以降は、選択したGoogleアカウントで自動的にログインされます。

【Googleログインのメリット】
  • パスワードを覚える必要がない
  • より安全なログイン方式
  • ワンクリックでログイン可能
【パスワードを忘れた場合】

ログイン画面の「パスワードをお忘れですか？」リンクから、パスワードリセットの手続きができます。登録したメールアドレスにリセット用のリンクが送信されます。

【組織での利用について】

企業や店舗で複数人で利用する場合、管理者から「店舗コード」が提供されます。登録時にこのコードを入力することで、組織内での練習履歴や統計を共有できます。

事前準備

必要なもの

  1. パソコンまたはスマートフォン
    • Chrome、Safari、Edgeなどのモダンブラウザ
    • マイク機能が使えるデバイス
  2. 静かな環境
    • 音声認識の精度を上げるため、できるだけ静かな場所で利用してください
  3. イヤホン・ヘッドセット（推奨）
    • スピーカーからの音声をマイクが拾ってしまうのを防ぎます
【初回アクセス時の注意】

初めてアクセスすると、ブラウザから「マイクの使用を許可しますか？」と聞かれます。必ず「許可」を選択してください。許可しないと音声入力ができません。

基本的な使い方

以下の手順で、ロープレを始めることができます。

ステップ1：システムにアクセス

ブラウザでシステムのURLを開き、ログインします。

ログイン後、ロープレシステムのトップページが表示されます。

ステップ2：シナリオを選択

トップページ画面上部にある「シナリオ」のドロップダウンメニューをクリックします。

以下のシナリオから選択できます（ロールにより異なります）：

【営業シナリオ】
  • 1次面談（初回接触・関係構築）：初心者向け - クライアントの警戒心を解き、信頼関係を構築
  • 1.5次面談（関係構築・情報交換）：初心者～中級者向け - 具体的な情報を聞き出し、サービス詳細を説明
  • 2次面談（提案・検討）：中級者向け - 具体的な提案を行い、検討してもらう
  • 3次面談（クロージング・契約）：中級者～上級者向け - 最終確認を行い、契約につなげる
  • キックオフMTG（プロジェクト開始）：全営業レベル - 契約後の初回ミーティング
  • 追加営業（既存顧客への提案）：中堅～ベテラン営業 - 既存顧客への追加提案
【ディレクターシナリオ】
  • 初回ヒアリング（制作要件の聞き出し）：新人～中堅ディレクター - クライアントから制作要件を聞き出す
  • キックオフMTG（制作開始）：全ディレクターレベル - 契約後の制作開始ミーティング

選択したシナリオは画面に表示され、そのシナリオに応じたクライアントの態度や会話の流れが設定されます。

ステップ3：ロール・難易度・ペルソナを選択

画面中央の「ペルソナ選択」ボタンをクリックすると、ロープレ設定モーダルウィンドウが開きます。

モーダル内で以下の4つの項目を順番に選択します：

1. ロール選択

練習したい役割を選択します：

  • 営業として練習 💼：ショート動画制作サービスの営業として、クライアントへの提案営業を練習
  • ディレクターとして練習 🎬：制作ディレクターとして、クライアントからの制作要件のヒアリング・提案を練習
2. シナリオ選択

選択したロールに応じて、対応するシナリオがドロップダウンメニューに表示されます。

  • 営業：1次面談、1.5次面談、2次面談、3次面談、キックオフMTG、追加営業の6種類
  • ディレクター：初回ヒアリング（制作要件の聞き出し）
3. 難易度レベル

クライアント（お客様）の態度や質問の難易度を3段階から選べます：

  • 初級 ⭐：クライアントが協力的で、質問に丁寧に答えてくれます
  • 中級 ⭐⭐：適度に警戒心があり、スキルに応じて態度が変わります（推奨）
  • 上級 ⭐⭐⭐：警戒心が強く、簡単には心を開きません
4. 顧客ペルソナ選択

クライアントの業種や設定を選択します：

  • おまかせボタン：システムがランダムに業種を選択（推奨）
  • 個別選択：美容サロン、飲食店、不動産、フィットネス、小売店などから選択

ペルソナを選択すると、そのクライアントの業種、現状、課題、予算感などが自動的に設定されます。

【初めての方へ】

最初は「営業ロール」で「中級」の難易度、「おまかせ」ボタンを押すのがおすすめです。様々な業種のクライアントと話すことで、対応力が身につきます。

ステップ4：ロープレ開始

ペルソナを選択すると、自動的にロープレが開始されます。

画面の構成：

  • 上部：現在のロール、シナリオ名、ペルソナ情報（業種など）が表示
  • 中央：会話履歴が表示されます（あなたとクライアントの発言）
  • 下部：大きな丸いマイクボタンと「講評をもらう」ボタン

会話の進め方：

  1. 画面中央下部のマイクボタンを長押しします
  2. マイクボタンが赤くなったら、話し始めます
  3. 話し終わったら、マイクボタンから指を離します
  4. 音声が認識され、テキストとして会話履歴に表示されます
  5. AIクライアント（お客様）が音声で返答し、その内容も会話履歴に表示されます
  6. このやり取りを繰り返して、会話を進めます
【上手に話すコツ】
  • マイクボタンを押してから、0.5秒待ってから話し始める
  • ゆっくり、はっきりと話す（早口にならない）
  • 一文ごとに区切って話す（長すぎる文は避ける）
  • イヤホン・ヘッドセットを使うと音声認識の精度が上がります
【会話のポイント】
  • 営業ロール：クライアントの挨拶から始まり、ヒアリング → 提案 → クロージングと進めます
  • ディレクターロール：クライアントの挨拶から始まり、制作目的のヒアリング → ターゲット確認 → 方向性提示 → 納期・予算確認と進めます
  • 挨拶だけで終わらず、最低でも5往復以上は会話を続けることをおすすめします

ステップ5：講評を受け取る

会話が一段落したら、画面下部の「講評をもらう」ボタンをクリックします。

GPT-4が会話全体を分析し、詳細な講評を生成します（数秒～数十秒かかります）。

講評画面の内容：

  • 総合スコア：4項目の平均点（5点満点）
  • 4項目の評価（ロールにより異なります）：
    • 営業ロール：質問力、傾聴力、提案力、クロージング力
    • ディレクターロール：ヒアリング力、企画提案力、コミュニケーション力、プロジェクト管理力
  • 各項目の詳細：
    • スコアの理由
    • 具体例（あなたの実際の発言が引用されます）
  • 良かった点：3～5項目（具体的な発言を引用）
  • 改善点：3～5項目（具体的な改善方法を提示）
  • 総合評価：全体の印象と次回へのアドバイス
  • 次回のアクションプラン：次のロープレで実践すべきこと3つ

講評は自動的にデータベースに保存され、「履歴」ページからいつでも確認できます。

【講評を最大限活用するために】
  • 「改善点」に記載された具体的な改善方法を、次回のロープレで実践する
  • 「良かった点」は継続して実践する
  • 「次回のアクションプラン」を意識して練習する
  • 同じシナリオを繰り返し練習して、スコアの向上を確認する

シナリオの説明

シナリオは、ロール（営業・ディレクター）と商談フェーズに応じて複数用意されています。

営業シナリオ（6種類）

営業の商談フェーズに応じて、6種類のシナリオが用意されています。

1次面談（初回接触・関係構築）

初心者向け 初回接触

目標：お客様の警戒心を解き、信頼関係を構築する

お客様の態度：慎重で、あまり多くを話してくれない

重点スキル：

  • ヒアリング力（30%）：現状を自然に聞き出す
  • 共感力（30%）：不安を受け止める
  • 提案力（20%）：押し売りせず、軽い提案をする
  • 信頼構築（20%）：次回面談につなげる

会話の流れ：挨拶 → ニーズ分析 → 軽い提案 → 次回アポイント

1.5次面談（関係構築・情報交換）

初心者～中級者向け 2回目の接触

目標：2回目の面談。少し打ち解けてきた状態で、具体的な情報を聞き出し、サービス詳細を説明する

お客様の態度：前回より少しフランクに話す。具体的な質問（費用、期間、実績など）を増やす

重点スキル：

  • 質問力（35%）：深掘りする質問ができるか
  • 傾聴力（30%）：話をしっかり聞けるか
  • 提案力（20%）：方向性を示せるか
  • 信頼構築（15%）：さらに関係を深める

会話の流れ：前回の振り返り → 具体的な情報交換 → サービス説明 → 次回提案の予告

2次面談（提案・検討）

中級者向け 3回目の接触

目標：具体的な提案を行い、お客様に検討してもらう段階

お客様の態度：前向きだが慎重。費用対効果や他社との比較を重視する

重点スキル：

  • 提案力（40%）：具体的で魅力的な提案ができるか
  • 質問力（25%）：懸念点を引き出せるか
  • 傾聴力（20%）：フィードバックを受け止められるか
  • クロージング（15%）：次のステップを提示できるか

会話の流れ：挨拶 → 提案説明 → 質疑応答 → 懸念解消 → 次回クロージングの予告

3次面談（クロージング・契約）

中級者～上級者向け 4回目の接触

目標：最終確認を行い、契約につなげる

お客様の態度：ほぼ決定に向かっているが、最終確認が必要

重点スキル：

  • クロージング力（50%）：自然に契約につなげられるか
  • 提案力（20%）：最終条件を整理できるか
  • 質問力（20%）：最終確認事項を漏れなく把握できるか
  • 共感力（10%）：残る懸念に寄り添えるか

会話の流れ：挨拶 → 最終確認 → 懸念解消 → 契約条件の確認 → クロージング

キックオフMTG（プロジェクト開始）

全営業レベル プロジェクト開始

目標：契約後の初回ミーティング。スムーズな進行管理と協力関係の構築

お客様の態度：既にクライアントとなっているため、協力的で前向き

重点スキル：

  • ヒアリング力（30%）：必要な準備を確認できるか
  • 信頼構築（30%）：協力関係を築けるか
  • 提案力（20%）：進行計画を明確に提示できるか
  • 共感力（20%）：期待や不安に寄り添えるか

会話の流れ：挨拶 → プロジェクト説明 → 準備の確認 → スケジュール共有

追加営業（既存顧客への提案）

中堅～ベテラン営業 既存顧客フォロー

目標：既存顧客への追加提案。新たな価値を提案する力が求められる

お客様の態度：信頼関係はあるが、予算は限られている。費用対効果を厳しく見る

重点スキル：

  • 提案力（40%）：新たな価値を提案できるか
  • ヒアリング力（20%）：現状の課題を把握できるか
  • 共感力（20%）：予算の懸念に寄り添えるか
  • 信頼構築（20%）：信頼関係を維持しつつ提案できるか

会話の流れ：挨拶・現状確認 → ニーズ分析 → 新規提案 → 懸念対応 → クロージング

ディレクターシナリオ（2種類）

【ディレクター】初回ヒアリング（制作要件の聞き出し）

新人～中堅ディレクター 初回ヒアリング

目標：クライアントとの初回ヒアリング。制作の目的、ターゲット、納期、予算などの要件を丁寧に聞き出し、制作の方向性を固める

お客様の態度：動画制作は初めて、または詳しくない。何から話せばいいか戸惑うこともある。良い質問をすると詳しく話す

重点スキル：

  • ヒアリング力（30%）：制作の目的・背景を丁寧に聞き出せるか
  • 企画提案力（25%）：ターゲット・イメージ・方向性を引き出せるか
  • コミュニケーション力（25%）：専門用語を避け、分かりやすく会話できるか
  • プロジェクト管理力（20%）：納期・予算・工程の確認ができるか

会話の流れ：挨拶 → 制作目的ヒアリング → ターゲット確認 → スケジュール確認 → まとめ

【ディレクター】キックオフMTG（制作開始）

全ディレクターレベル プロジェクト開始

目標：契約後の初回ミーティング。制作の進め方、コンテンツの方向性、スケジュール、準備物の確認

お客様の態度：既にクライアントとなっているため、協力的で前向き。進め方やスケジュールを確認したい

重点スキル：

  • 企画提案力（30%）：制作スケジュールと進行計画を明確に提示できるか
  • ヒアリング力（25%）：クライアントの期待や要望を丁寧に聞き出せるか
  • コミュニケーション力（25%）：分かりやすく説明し、クライアントの不安を解消できるか
  • プロジェクト管理力（20%）：準備物・納期・役割分担を整理できるか

会話の流れ：挨拶 → スケジュール確認 → コンテンツ方向性の相談 → 準備物確認 → 次のステップ

注意：既に契約済みのため、費用や見積の話はしません。進め方と内容の打ち合わせが中心です。

【シナリオの選び方】
  • 営業初心者：まずは「1次面談」から始めましょう
  • 営業で慣れてきたら：1次→1.5次→2次→3次と順番に練習すると、商談の流れが体得できます
  • ディレクター初心者：「初回ヒアリング」でクライアントからの要件聞き出しを練習しましょう
  • 特定スキルを鍛えたい：苦手なフェーズを重点的に練習しましょう

ペルソナの選び方

ペルソナとは、AIクライアント（お客様）の「設定」のことです。業種、現状、課題、予算感などが設定されています。営業・ディレクターどちらのロールでも、同じペルソナを使用します。

ペルソナの種類

業種 特徴 難易度
美容サロン Instagram重視、ビジュアル重視 中
飲食店 予算に敏感、効果を重視 中
不動産 堅実、データ重視 高
フィットネス SNS活用に前向き 中
小売店 コスト重視、効果測定に敏感 高

選び方のポイント

【おまかせ（ランダム選択）がおすすめな理由】
  • 様々な業種のクライアントと話すことで、対応力が身につく
  • 予想外の質問や展開に対応する練習になる
  • 実際の営業・ディレクター業務では、様々な業種のクライアントと話す機会があるため、実践的
【特定の業種を選ぶ場合】
  • 担当エリアに多い業種を重点的に練習したい
  • 苦手な業種を克服したい
  • 特定の業種の知識を深めたい
  • ディレクターの場合、特定業種の制作要件パターンを学びたい

講評の見方

ロープレ終了後、GPT-4があなたの会話を分析し、選択したロールに応じた4項目で評価します。

営業ロール - 評価項目（4項目）

1. 質問力（Questioning Skill）

顧客のニーズや課題を適切に引き出す質問ができているか

良い例：

  • 「現在、動画制作で困っていることはありますか？」
  • 「月に何本くらいの投稿を目標にされていますか？」

改善点の例：

  • 抽象的すぎる質問（「何かお困りですか？」）
  • クローズドクエスチョンばかり（「動画は作っていますか？」→「はい/いいえ」で終わる）

2. 傾聴力（Listening Skill）

相手の発言を理解し、適切に受容・共感できているか

良い例：

  • 「なるほど、外注コストが課題なんですね」
  • 「確かに、毎月の制作は大変ですよね」

改善点の例：

  • お客様の話を遮る
  • 共感せずに次の質問に移る

3. 提案力（Proposal Skill）

顧客の課題に対する具体的な解決策を提示できているか

良い例：

  • 「月10本のショート動画を定額で制作できます」
  • 「Instagram用に縦型動画を作成し、リール投稿をサポートします」

改善点の例：

  • 抽象的な提案（「動画制作をお手伝いします」）
  • お客様のニーズと合っていない提案

4. クロージング力（Closing Skill）

次のアクションや決定を促す適切なクロージングができているか

良い例：

  • 「次回、具体的なプランをご提案させていただけますか？」
  • 「来週、サンプル動画をお持ちしますね」

改善点の例：

  • 次のステップを提示せずに終わる
  • 強引すぎるクロージング（「今日決めてください」）

ディレクターロール - 評価項目（4項目）

1. ヒアリング力（Hearing Skill）

制作要件を丁寧に聞き出し、情報を整理する能力があるか

良い例：

  • 「今回の動画制作の目的は何でしょうか？」
  • 「ターゲットとなるお客様はどのような方々ですか？」
  • 「現在、どのような課題を感じていらっしゃいますか？」

改善点の例：

  • 制作目的を確認せずに話を進める
  • クライアントの話を遮って自分の意見を述べる

2. 企画提案力（Planning Skill）

クライアントの課題に対する具体的な解決策・方向性を提示できているか

良い例：

  • 「20代女性がターゲットでしたら、Instagramリール形式がおすすめです」
  • 「商品の使い方を紹介する動画と、お客様の声を紹介する動画の2パターンはいかがでしょうか」

改善点の例：

  • 抽象的な提案（「良い動画を作りましょう」）
  • クライアントのニーズと合っていない方向性の提示

3. コミュニケーション力（Communication Skill）

専門用語を避け、分かりやすく説明し、共感・信頼関係を構築できているか

良い例：

  • 「エンゲージメントというのは、動画への反応のことです」（専門用語の説明）
  • 「初めての動画制作は不安ですよね。丁寧にサポートいたします」（共感）

改善点の例：

  • 専門用語を説明なしに使う
  • クライアントの不安や疑問に寄り添わない

4. プロジェクト管理力（Project Management Skill）

納期・予算・工程の確認と調整ができているか

良い例：

  • 「納期はいつまでにご希望ですか？」
  • 「ご予算の目安を教えていただけますか？」
  • 「撮影は2日、編集に3日、合計5営業日で完成します」

改善点の例：

  • 納期や予算を確認しないまま進める
  • 制作工程の説明が曖昧

スコアの見方

スコア 評価 説明
5点 非常に優れている プロレベル、模範的なトーク
4点 優れている 実践的なスキルが十分にある
3点 平均的 基本スキルはあるが、改善点が複数ある
2点 要改善 基本スキルが不足している
1点 大幅な改善が必要 スキルがほとんど発揮されていない
【講評の活用方法】
  • 良かった点：次回も継続して実践しましょう
  • 改善点：具体的な改善方法が書かれているので、次回のロープレで意識しましょう
  • 具体例：自分の実際の発言が引用されているので、振り返りに活用しましょう
  • 次回のアクションプラン：次のロープレで実践すべきことが3つ提示されます
  • ロール別の重点：営業は商談スキル、ディレクターはヒアリング・企画スキルが重点評価されます

使いこなすコツ

1. 会話を長く続けるコツ

  • 挨拶だけで終わらず、必ずヒアリング → 提案 → クロージングまで進める
  • お客様の回答に対して、さらに深掘りする質問をする
  • 会話の途中で「講評をもらう」を押さず、自然な終わり方を目指す

2. スコアを上げるコツ

営業ロールの場合：

  • 質問力：オープンクエスチョンを使う（「どのような～」「何が～」）
  • 傾聴力：お客様の発言を要約して確認する（「つまり～ということですね」）
  • 提案力：具体的な数字を使う（「月10本」「月額5万円」など）
  • クロージング力：必ず次のアクションを提示する

ディレクターロールの場合：

  • ヒアリング力：制作目的・ターゲット・イメージを丁寧に聞き出す
  • 企画提案力：クライアントの課題に合った具体的な方向性を提示する
  • コミュニケーション力：専門用語を避け、分かりやすく説明する
  • プロジェクト管理力：納期・予算・工程を明確に確認する

3. 音声認識の精度を上げるコツ

  • マイクボタンを押してから、0.5秒待ってから話し始める
  • ゆっくり、はっきりと話す（早口にならない）
  • 一文ごとに区切る（長い文は避ける）
  • イヤホン・ヘッドセットを使う
  • 静かな環境で練習する

4. 効果的な練習方法

  • 毎日少しずつ：1日1回、10分だけでも続ける
  • シナリオを順番に：1次→1.5次→2次→3次と順番に練習
  • 同じシナリオを繰り返す：1つのシナリオを3回以上練習すると、パターンが身につく
  • 講評を読み返す：次のロープレ前に、前回の講評を見直す

よくある質問

Q1. AIクライアントが「すみません、もう一度お願いできますか？」と頻繁に言います

A. 以下を確認してください：

  • 静かな環境で話していますか？
  • マイクボタンを押してから、0.5秒待ってから話していますか？
  • 一文が長すぎませんか？（一文は20文字程度が理想）
  • イヤホン・ヘッドセットを使っていますか？

Q2. 講評のスコアが低いです

A. スコアが低い場合、以下の可能性があります：

  • 挨拶だけで終わっている → ヒアリング、提案、クロージングまで進めましょう
  • 基本的な質問しかしていない → 深掘りする質問を意識しましょう
  • 会話が短すぎる → 最低でも5往復以上は会話しましょう

講評の「改善点」をよく読んで、次回のロープレで実践してみてください。

Q3. AIクライアントの声が聞こえません

A. 以下を確認してください：

  • デバイスの音量がミュートになっていませんか？
  • ブラウザの音声再生が許可されていますか？
  • イヤホンやスピーカーが正しく接続されていますか？

Q4. 会話の途中でやり直したいです

A. 画面右上の「リセット」ボタンをクリックすると、会話をやり直せます。

Q5. 講評はどこに保存されますか？

A. 講評は自動的にデータベースに保存されます。過去の講評は「履歴」から確認できます。

Q6. スマホでも使えますか？

A. はい、スマートフォンのブラウザでも利用できます。Chrome、Safariなどのモダンブラウザを使用してください。
