## 🎯 実装内容

### 1. ペルソナ毎に音声が変わらない問題の修正

**問題**:
- 「アパレルEC」が「EC」判定に先にマッチして`mid_manager` (Neural2-B) になっていた
- 本来は`young_entrepreneur` (Neural2-C) になるべき

**原因分析**:
```python
# 誤った判定順序
if 'アパレル' in business_type:  # ❌ 「アパレルEC」にマッチしない
    persona_type = 'young_entrepreneur'
elif 'EC' in business_type:      # ✅ 先にマッチしてしまう
    persona_type = 'mid_manager'
```

**修正内容**:

より具体的な条件を先に判定するように順序を変更:

```python
# 🎯 判定順序重要: より具体的な条件を先に判定

# 美容/アパレル → young_entrepreneur (明るく快活) ⚠️ 「アパレルEC」を先に判定
if '美容' in business_type or 'サロン' in business_type or 'アパレル' in business_type:
    persona_type = 'young_entrepreneur'  # Neural2-C, 1.2
# ...
# EC/オンライン → mid_manager (標準的) ⚠️ より一般的な条件は最後に
elif 'EC' in business_type or 'オンライン' in business_type:
    persona_type = 'mid_manager'  # Neural2-B, 1.2
```

**修正箇所**:
- `blueprints/conversations.py` (2箇所)
  - 初回ペルソナ選択時の判定ロジック（839-868行目）
  - TTS生成時の判定ロジック（694-723行目）

**期待される動作**:
| 業種 | ペルソナタイプ | 音声 | 話速 | 特徴 |
|------|------------|------|------|------|
| **アパレルEC** | young_entrepreneur | **Neural2-C** ✅ | 1.2 | 明るく快活 |
| **運送会社** | traditional_owner | **Neural2-B** ✅ | 1.1 | 落ち着いた声 |

### 2. 1回の会話中で音声が変わる問題の修正

**問題**:
- 1回目のメッセージ: ペルソナ受信・音声設定保存 ✅
- 2回目のメッセージ: `persona: なし` → 音声設定が失われる ❌

**原因分析**:

**Reactのクロージャー問題**: `handleSendStream`関数が定義された時点の`currentPersona`の値をキャプチャしてしまい、後で`setCurrentPersona`で更新されても反映されない。

```
1. 初回レンダリング: currentPersona = null → handleSendStream定義（null をキャプチャ）
2. 1回目応答: ペルソナ受信 → setCurrentPersona(persona) → currentPersona更新
3. 2回目メッセージ: handleSendStream実行 → まだ null を参照 ❌
```

**ログからの問題特定**:
```
[ペルソナ監視] currentPersonaが更新されました: Object  ← ステートは更新されている
[API送信] conversation_id: null, persona: なし  ← 関数内では null のまま
```

**修正内容**:

`currentPersonaRef`を追加してクロージャー問題を回避:

1. **Ref追加** (`src/RoleplayApp.tsx:62`):
   ```typescript
   const currentPersonaRef = useRef<any>(null);
   ```

2. **useEffectで同期** (`src/RoleplayApp.tsx:248-254`):
   ```typescript
   useEffect(() => {
     currentPersonaRef.current = currentPersona;
     console.log('[ペルソナ監視] currentPersonaが更新されました:', ...);
   }, [currentPersona]);
   ```

3. **handleSendStream内で使用** (`src/RoleplayApp.tsx:563-570`):
   ```typescript
   const personaToSend = currentPersonaRef.current; // Refから最新値を取得
   // ...
   body: JSON.stringify({
     // ...
     persona: personaToSend // 現在のペルソナを送信
   }),
   ```

4. **録画保存時も修正** (`src/RoleplayApp.tsx:1306`):
   ```typescript
   persona: currentPersonaRef.current,
   ```

**期待される動作**:
| タイミング | 動作 |
|----------|------|
| 1回目メッセージ | ペルソナ選択 → 音声設定保存 → フロントエンドに送信 |
| 2回目メッセージ | **`currentPersonaRef.current`を送信** ✅ → バックエンドで使用 |
| 3回目以降 | 同じペルソナを継続使用 → **会話内で同じ音声を維持** ✅ |

**コミット**: `19ab10b`
